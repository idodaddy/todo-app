## 종합 리뷰

### 1단계: 변경 파일 확인
`git diff --name-only`로 변경된 파일 목록을 확인하세요.
변경 파일이 없으면 `git diff main --name-only`를 시도하세요.

### 2단계: 코드 리뷰
code-reviewer 서브에이전트로 변경된 파일을 리뷰하세요.

### 3단계: 테스트 확인
- 변경된 코드에 대한 테스트가 있는지 확인
- 없으면 test-writer 서브에이전트로 테스트 추가

### 4단계: 종합 보고
- 🔴 Critical 이슈 (반드시 수정)
- 🟡 Warning (검토 필요)
- ✅ 통과 항목
